# TutGo — AI Assistant

Фрагмент кода AI-ассистента платформы TutGo (tutgo.uz) — сервиса онлайн-бронирования услуг в Ташкенте.

Файл `index.ts` — ядро AI-ассистента (Supabase Edge Function): принимает запрос пользователя на естественном языке, ищет релевантные заведения/услуги в базе данных, формирует контекст и передаёт его в LLM для генерации ответа (RAG-пайплайн).

Полный проект: [tutgo.uz](https://www.tutgo.uz)
